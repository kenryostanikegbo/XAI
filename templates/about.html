About this Dashboard

This dashboard is the deployment deliverable for the dissertation Predicting Student Failure with Explainable Machine Learning, which uses the Open University Learning Analytics Dataset (OULAD; Kuzilek et al., 2017).

Methodology in brief

  • Six of the seven OULAD tables are integrated; Withdrawn students are excluded (final outcome ambiguous).
  • The modelling matrix has 22,311 rows and 44 one-hot columns; the held-out test set has 6,732 rows.
  • Two classifiers: Logistic Regression with L2 regularisation, and a Random Forest with 500 trees.
  • Tuning: 5-fold stratified GridSearchCV on F1, with SMOTE inside the cross-validation pipeline (no leakage).
  • Interpretability: LinearSHAP for the LR (log-odds) and TreeSHAP for the RF (probability).
  • Test-set evaluation: ROC-AUC = 0.957 (LR) and 0.962 (RF). F1 = 0.840 (LR) and 0.859 (RF).

What the dashboard shows

  • Home: model card, performance metrics, ROC/PR curves, both confusion matrices.
  • Global SHAP: both beeswarms, both mean-|SHAP| bar charts, the cross-model comparison.
  • Local Cases: the six illustrative cases from Chapter 4 §4.7 with deep links.
  • Any /student/<row_idx> page: live predictions and a JSON-rendered waterfall for any test row.

Limitations

  • Single institution, single dataset; cross-institutional transfer is an open question.
  • Withdrawn students are excluded; the model cannot flag withdrawal risk.
  • All 21 features are aggregated over the full presentation; no temporal trajectory.
  • SHAP values are statistical associations, not causal claims.
  • Threshold sensitivity and feature-scale robustness checks are out of scope of this deployment.

Reproducibility

The dashboard reuses the dissertation's saved artifacts in outputs/models/ and outputs/figures/. No retraining happens at runtime. The full pipeline is reproducible from a clean clone of the repository in under 45 minutes on a standard laptop, with a fixed random seed at every stochastic stage.
